# Attribution

`LICENSE` covers the **code** in this repository. This file governs everything
else: audio that is redistributed here, and data that is not.

The distinction matters because some of the material this project measured
cannot be redistributed at all, and some can only be redistributed with credit.
A single permissive licence over the whole repository would implicitly grant
rights to audio that nobody here can grant.

## Audio redistributed in this repository

### Impulse responses — third-party, credit required

`code/models/3.6_differentiable_reverberation/weights/irs/` contains three
measured impulse responses from the **EchoThief Impulse Response Library** by
Christopher Warren (<http://www.echothief.com/>), free to use with credit.

They ship because Section 3.6's stimulus ladder convolves the *actual
measurement* rather than an approximation of it, so the ladder cannot be
rendered without them. Only three of the library's 115 spaces are needed.
`weights/irs/ATTRIBUTION.md` repeats this beside the files, so a copied
directory keeps its credit.

### Everything else — output of this project

| Path | What it is |
|---|---|
| `audio/` | rendered clips the report refers to |
| `code/models/*/data/samples/` | sample outputs, regenerated by the command in each `samples/README.md` |
| `figures_3d/` | interactive figures |

These are generated by the code here and carry the same terms as the code, with
one caveat worth stating: Section 3.6's samples are renders of a synthetic
source *through* the EchoThief impulse responses above, so they are derivative
of that library and inherit its credit requirement.

## Data measured but NOT redistributed

Nothing below ships. What ships is **measurements of it** — numbers, fitted
parameters, and derived statistics, which are this project's own work.

| Source | Terms | What ships instead |
|---|---|---|
| Commercial ambient recordings | all rights reserved | fitted dwell windows and transition rates (§3.5), fitted decay and damping (§3.6) |
| NSynth | CC BY 4.0 | the measured timbre prior (§3.3) |
| DEAM | research use, registration | ridge-head coefficients (§3.4.1) |
| Emo-Soundscapes | academic, non-commercial | ridge-head coefficients (§3.4.1) |
| Essen Folksong Collection | free for research | the fitted grammar (§3.7) |
| MERT-v1-95M | CC BY-NC 4.0 | downloaded on first use; not vendored |
| audEERING wav2vec 2.0 | CC BY-NC-SA 4.0 | downloaded on first use; not vendored |

Where a source's own identity was used as a label — reverb conditions named
after the artists whose acoustics were measured, melody styles named after
performers — those labels have been re-keyed onto the measurements they
describe. The numbers are unchanged; see §3.6 and §3.7.

## Human participants

Rating data ships pseudonymised. Identifiers are `R01`…`R26`, consistent across
every study, plus one anonymous id the rating app minted for an outside rater.
The mapping from real identities is not in this repository and was not derived
by guesswork: it was recovered by aligning against the report's own
pseudonymised copies, so the two agree.

No participant name, email, handle, or absolute path to a personal directory
appears anywhere in what ships. `python code/verify.py` checks this.

## Background beds

The conductor's background beds come from two public corpora and are **not**
redistributed in full: ESC-50 (CC BY-NC 3.0) and Emo-Soundscapes (Creative
Commons, assembled from Freesound). One bed per type ships so the bed layer
works without a download, chosen to favour the most permissive licence
available for that type.

Each shipped file is credited individually — corpus, licence, contributor and
original source — in
[`code/conductor/assets/beds/ATTRIBUTION.md`](code/conductor/assets/beds/ATTRIBUTION.md),
with credits read from the corpora's own records rather than transcribed.
