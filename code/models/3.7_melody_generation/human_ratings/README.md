# Human ratings — none in this directory

The melody model was selected by validation loss and by listening, not by a
rating study. The listening comparisons that touched melody are part of the
component-preference study and live in
`3.9_human_evaluation_and_protocols/human_ratings/`, where `test == "melody"`
carries 181 rows.

Note for whoever writes this up: the deployed checkpoint is the six-layer
L6/d128 model, not the three-layer one. See §7.1 of the top-level README.
